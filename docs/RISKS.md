# 尚未達成項目與風險

- **高：示範 token 非認證。** 固定 token 可由頁面選單取得；任何可連線的人都能切換示範角色。服務只綁 loopback 作開發示範，禁止曝露網路或放入學生資料。
- **高：無正式租戶及持久化授權模型。** 班級/群組假名存於 token map；研究同意是合成種子列。需在校方提供治理決策後改為正式授權和同意版本記錄。
- **中：SQLite 單機資料層。** MVP-001 已有可重跑增量 migrations，仍沒有水平擴充、備份排程、資料保留刪除機制。
- **中：Docker 未驗證。** Docker CLI 不在目前 Windows PATH，Compose 只能交付設定，不能宣稱已成功建置或啟動。
- **中：尚無離線閾值計算、sensor correction records、能力設定 API、使用者速率限制、CORS/CSRF/TLS、安全日誌清理或依賴掃描。
- **中：M13 影像人工標註僅有 table stub。** 沒有上傳、私有物件儲存、授權核對或兒童影像保護流程。
- **中：M19 已有同指標 SVG 圖及 reading_id，尚無 100,000 筆 P95 基準。** readings API 仍最多回傳 500 筆；圖表不能作因果結論。
- **中：Mock hints 固定問題。** 有介入持久紀錄與教師覆核 API，尚無教師 UI 停用設定或可替換 provider 執行時安全政策引擎。
- **中：研究匯出為保護個資而省略所有自由文字。** 仍需正式研究團隊核定資料最小化與文字人工審核/去識別工作流。
- **待確認：** 感測器型號/精度/頻率、正式帳號與校別架構、研究倫理核准/同意條款、資料保留期限、雲端模型供應商/預算、正式課程日期及部署環境。
