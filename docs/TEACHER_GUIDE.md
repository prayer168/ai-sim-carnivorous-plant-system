# 教師操作手冊（本機假名示範）

1. 啟動服務並進入首頁。教師角色建立 M01、M09、M13、M19、M24 或 M25 任務；此版同班示範學生可見任務。
2. 選「學生 G01」，提交觀察並記下回傳 observation_id；提交 `pre_ai` 初答，原稿鎖定。更正觀察要附 `original_version_id`，回應修訂則選 `revised` 階段。
3. 初答送出後選「取得 Mock 引導問題」。系統保存 prompt/model 版本、問題、安全旗標與不確定性；問題只提供追問方向。教師可用介入紀錄的 review API 留下覆核。
4. 設備模擬器執行九格測值。請記下上報回傳的 reading_id（API 回傳；網頁目前只摘要回應）。缺測為 null/missing，設備離線依最後觀測時間判斷。
5. 分析至少引用兩筆 reading_id；每個圖表點都回傳 reading_id。CER 表單引用 observation_id、reading_id 或 analysis_id；不存在或越權來源會被拒絕。
6. 教師以 S001 假名和三向度 1–4 級保存人工評量。教師評分和研究匯出均寫入稽核紀錄。
7. 研究者建立匯出後，以回傳 download_path 取得 ZIP。ZIP 含 JSON/CSV、字典和 SHA-256 manifest；未同意假名 S002 排除，學生自由文字不輸出。
8. 重新登入/重新整理後按「重新載入並恢復工作進度」查閱六階段狀態。

讀值的 UTC 時間在瀏覽器可依使用者時區呈現；缺測用 null/`missing`，不可解讀為 0。九格共用環境/燈源標籤提醒教師：監測點不是九個獨立實驗複本。此示範沒有學生登入密碼或正式研究同意程序。
